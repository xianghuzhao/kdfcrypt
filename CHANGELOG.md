# Changelog

## v1.6.0

### Changed

- Update the default Argon2id, scrypt, and PBKDF2 password-hashing parameters
  to the current OWASP baseline.
- Generate a 16-byte random salt when `Encode` is called without a salt
  configuration.
- Require canonical encoded strings and reject unknown, duplicate, missing,
  overflowing, and invalid KDF parameters.
- Require Go 1.25 and update `golang.org/x/crypto` and `golang.org/x/sys`.
- Use the Go standard library implementation of HKDF.

### Added

- Add `ErrInvalidEncoding`, `ErrInvalidParameter`, and
  `ErrUnsupportedAlgorithm` for programmatic error classification.
- Add Linux CI for Go 1.25 and Go 1.26.

### Compatibility

- Existing encoded hashes generated by kdfcrypt continue to verify because
  their algorithm and parameters are embedded in the encoded value.
- New defaults affect only calls that omit the corresponding parameters.
- Non-canonical strings that depended on the previous permissive parser are
  rejected.
